# v0.1.0-preview.1

重新发布修复：通过只读调用验证受保护的 FName 构造器；修复菜单库模块隔离时误改内部变量名的问题。两处错误都会导致正确安装后 F8 无法打开菜单。新增菜单库加载与完整入口启动测试，覆盖私有依赖加载、FName 检查及 F8 注册。

- F8 菜单召唤、重新召唤、移除独立人形训练目标，默认 10000 生命。
- 到 1 血自动回满；显示完整单次/累计生命伤害、命中和回血次数。
- 重置统计并回满血；仅排除木桩触发的战斗音乐。
- `config.ini` 支持映射菜单开关键，默认 F8，修改后重启生效。
- ModMenu / UEHelpers 私有打包，入口检查 UE4SS API。
- 同时提供 mod-only 与锁定 PBZ 专用 UE4SS 的整合包，由 GitHub Actions 验证、打包并发布。

适配 Steam build 26266538 / UE 5.7.4，以及 UE4SS v3.0.1-1183-gcdbc0b66。安装与卸载步骤见仓库 README。已有 UE4SS 使用 mod-only，避免运行库冲突。

预览版：游戏内功能已在现有加载器环境测试；独立上游加载器的整合安装、新的私有依赖布局与按键配置仍需冷启动回归。处决、所有持续伤害、场景切换和全部 Mod 组合尚未完成验证。CI 验证不等同于游戏内验证。
